# assets フォルダについて

## このフォルダの役割

`assets/` 配下のファイルは、**スライドの素材・下書き・生成図** を置くためのフォルダです。

| 種類 | 例 | 用途 |
|------|-----|------|
| 画像生成の出力 | `roc_pr.png`, `slide8_v1.png` | GPT Image 等で作った図の保存・pptx への貼り付け |
| データセット図の素材 | `gen_dev_data.png`, `dwon_stream_data_v2.png` | スライド作成時の参考・再利用 |

**ここにある画像は、発表スライドの「正」ではありません。**  
ファイル名や内容が、最終的なスライド番号・構成と一致しないことがあります。

---

## スクリプト・スライド構成を考えるときに参照するもの

発表スクリプト（`script/slideN.md`）やスライド構成を書く・直すときは、**必ず次を正とする**こと。

1. **発表者が添付・共有したスライド画像**（チャットに貼ったキャプチャ、エクスポート PNG など）
2. **本番 pptx**  
   [`英文抄読会_池口晃太_M2.pptx`](../英文抄読会_池口晃太_M2.pptx)（リポジトリ直下）

`assets/` の画像だけを見て、スライド10が何の内容かなどを推測しないこと。

---

## pptx を確認する方法（参考）

ターミナルでスライド本文をざっと見る例：

```bash
cd /Users/kouta_i5/Github/Personal/englisch_literaturrunde
unzip -p 英文抄読会_池口晃太_M2.pptx ppt/slides/slide10.xml | sed 's/<[^>]*>//g' | tr -s ' \n'
```

スライド番号 `slideN.xml` の `N` が、発表の **Slide N** に対応する（通常は 1 始まり）。

---

## 関連ファイルとの関係

| パス | 役割 |
|------|------|
| `script/slideN.md` | Slide N の口頭原稿・スライド文案 |
| `text_to_image_prompt/slideN.md` | 図を**新規生成するとき**のプロンプト（assets に出力されることもある） |
| `Readme.md` | 論文メモ・スライド構成の設計メモ（pptx と齟齛がある場合は pptx / 添付画像を優先） |
| `assets/*` | 素材置き場（構成の根拠にしない） |

---

## 運用ルール（AI・共同作業向け）

- スクリプト更新前に、対象スライドの **pptx または添付画像** を確認する。
- `assets/` のファイル名（例: `slied10.png` の typo）に引っ張られない。
- 新しい生成図を `assets/` に保存しても、**スライド番号と README の対応表は自動では更新されない**。pptx 側で枚数が変わったら `script/` と `発表スクリプト.md` を手動で揃える。
- 本番スライドのスクリーンショットを残す場合は、`assets/` ではなく、発表者が指定した場所（またはチャット添付）を「正」とする。
