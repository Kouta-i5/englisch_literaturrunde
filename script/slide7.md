## スクリプト

続いて、データセットです。左が生成モデル開発用データ 、すなわち「EyeDiffを作るためのデータ」、右が下流タスク評価用データ 、すなわち「できたEyeDiffが診断に役立つかを確かめるデータ」です。
まず左側なのですが、これは8つのデータセットから計42,048枚を集め、眼底写真やOCT、造影など14種類の画像に、疾患や病変の説明文を付けた画像とテキストのペアデータとなっています。
半数以上を占めるのがRetinal Image Bank（レティナル・イメージ・バンク）で、84種類の病変にわたります。そのほか、糖尿病網膜症が多いEyePACS、黄斑疾患などのOCTDL、緑内障向けのREFUGEやGAMMAなど、性質の異なるデータを組み合わせています。
次に右の評価用です。11データセット、うち内部2、外部9を、4つの診断タスクに割り当てます。糖尿病網膜症は、インドやフランスの3データセットで重症度5段階を予測します。
緑内障は、スペインと韓国の2データセットで、正常・早期・進行の3クラスです。
多疾患分類は、眼底のJSIECやRetina、OCTのOCTID・OCTDLを用います。希少疾患は、Retinal Image Bankの2019年以降から17疾患、約2,300枚をまとめたセットとなっています。

### データの流れ

```
【左】開発用8DS → EyeDiff学習 → 合成画像を生成
【右】評価用11DS → 実画像 ± 生成画像 → 基盤モデル → AUROC/AUPR
```
